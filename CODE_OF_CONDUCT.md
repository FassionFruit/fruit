
# Code of Conduct

## Our Commitment

FassionFruit is an open-source project built around collaboration, learning, and improving native interoperability.

We are committed to providing a welcoming and respectful environment for everyone, regardless of experience level, background, identity, or point of view.

## Expected Behavior

All participants are expected to:

- Be respectful and considerate.
- Provide constructive feedback.
- Respect differing opinions and technical approaches.
- Accept criticism gracefully.
- Focus on what is best for the project and its community.
- Help maintain a welcoming environment for all contributors.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, threats, or personal attacks.
- Discriminatory or offensive language.
- Publishing private information without permission.
- Deliberate disruption of project discussions.
- Any behavior that creates an unsafe or hostile environment.

## Scope

This Code of Conduct applies to all FassionFruit project spaces, including:

- GitHub repositories
- Issues and pull requests
- Discussions
- Other spaces where participants represent the project

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Maintainers may remove or reject contributions that violate these guidelines.

Depending on the severity of the violation, actions may include:

- A warning
- Temporary restrictions
- Removal from project spaces

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers privately through the FassionFruit GitHub organization.
